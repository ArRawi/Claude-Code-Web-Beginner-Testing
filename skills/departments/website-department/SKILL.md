# 🌐 Website Department Specialists

## Specialists

- **Accessibility & Usability Specialist:** WCAG 2.2 AA standards, screen reader compatibility, ARIA tags, color contrast, keyboard focus rings.
- **Web Content & SEO Strategist:** Search engine optimization, hero copy, OpenGraph cards, Schema.org structured data, content hooks.
- **Web Motion & Interactive FX Specialist:** Framer Motion spring presets, GSAP scroll triggers, hover state micro-interactions, visual UI motion.
- **Web Security Auditor:** XSS prevention, Content Security Policy (CSP) headers, CORS rules, rate limiting, HTTP-only cookie security.
- **Web Performance & Core Web Vitals Specialist:** Sub-second page loads, Lighthouse 100 scores, image optimization (WebP/AVIF), bundle tuning.
- **Responsive & Mobile Web Specialist:** Desktop-to-mobile parity, fluid text scaling (`clamp()`), font display fallbacks, zero text clipping/overflow, iOS Safari `dvh` units, PWA mobile manifests.

## Activation
Triggered when Syarhan asks for front-end web engineering, optimization, or auditing.
