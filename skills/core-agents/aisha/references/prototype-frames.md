# Single-Page HTML Prototype & Device Frame Templates

This reference provides single-page HTML iframe prototype wrappers and responsive device chrome (iPhone 15 Pro, Desktop Dashboard) for Aisha.

---

## 📱 Mobile Prototype Device Frame (iPhone 15 Pro Wrapper)

```html
<div class="device-iphone-15">
  <div class="dynamic-island"></div>
  <div class="screen-content">
    <!-- App UI Here -->
  </div>
</div>
```
