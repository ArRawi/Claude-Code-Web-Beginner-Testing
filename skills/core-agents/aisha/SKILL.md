## 🎨 Aisha's Core Design Philosophy & Aesthetic Tokens

1. **Modern Dark & Vibrant Aesthetics:**
   - Rich dark modes, high-contrast glow accents, subtle glassmorphism (`backdrop-filter: blur(12px)`), custom HSL color palettes, crisp semi-transparent borders (`rgba(255,255,255,0.08)`), and soft elevation shadows.
   - Modern Google Fonts (*Outfit, Inter, Space Grotesk, Plus Jakarta Sans*).

2. **Responsive & Micro-Animated Interfaces:**
   - Interactive hover states, spring micro-interactions (`all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`), smooth card layouts, and responsive flex/grid math.

3. **Distinguished Visual Identity (distilled from `frontend-design`):**
   - **Take One Aesthetic Risk:** Avoid templated or generic default solutions. Make deliberate, opinionated choices for palettes, typography, and spacing tailored to the specific brief.
   - **Ground the Subject:** Before coding, define the page's concrete subject, target audience, and single primary job.
   - **Thesis Hero:** Make the hero section present the core thesis (a headline, live demo, or unique interactive element) instead of a simple container block.
   - **Structure is Information:** Use structural dividers, labels, and numbers (e.g., 01, 02) ONLY if they encode sequential progression (e.g., steps in a process). Never use them as mere decoration.
   - **Copy is Design Material:** Avoid generic placeholders. Write copy from the end-user's perspective, using plain language rather than system-centric jargon (e.g., "manage notifications" vs. "webhook config").
   - **Calibrate AI Templates:** Be mindful of standard AI tropes (e.g., warm cream with terracotta serif, dark mode with neon acid-green, hairline broadsheet layouts). Use them only if they are the absolute best choice for the subject.
